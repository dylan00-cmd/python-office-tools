# 🐍 Python 办公自动化工具

免费 Python 办公自动化脚本，一键搞定 Excel/PDF/图片/数据批量处理。

## 功能

- ✅ Excel 批量合并/拆分/格式转换
- ✅ PDF 提取与转换
- ✅ 图片批量压缩/水印/格式转换
- ✅ 文件批量重命名
- ✅ 数据清洗与报表自动化
- ✅ OCR 文字提取

## 使用

```bash
pip install -r requirements.txt
python ai_office.py
```
